# 归位 FileRoute v3.2 — Android 17（API 37）

![归位 FileRoute 仓库封面](docs/FileRoute-AppCover-Android17.png)

程序图标：

![归位 FileRoute 程序图标](docs/FileRoute-AppIcon.png)

免 Root。当前版本 **3.2.0**（compileSdk 37 / targetSdk 37）。公共目录监听不需要 Shizuku；如果手机已安装并授权 Shizuku，还可以读取微信、QQ 等应用私有目录里的文件。

最低安装系统仍是 Android 8.0（API 26）。

请安装 v3.2.0。已安装 v3.1.0 的手机会在打开应用后收到更新提示。

## 这一版

1. 可选 Shizuku：用于读取 `Android/data` 下微信、QQ、TIM、钉钉、飞书的私有下载目录。未安装 Shizuku 时仍走公共目录。
2. 继续支持应用内检查 GitHub Release 并下载 APK。
3. 推送 `v*` 标签后，Actions 自动把 APK 附到对应 Release。

## 安装

打开 [v3.2.0-android17](https://github.com/legeng49/FileRoute-Android-NoRoot/releases/tag/v3.2.0-android17)，下载 `FileRoute-v3.2.0-android17.apk`。
